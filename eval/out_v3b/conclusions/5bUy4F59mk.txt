The central contribution of this paper is the Tool Decoding mechanism: a training‑free, plug‑and‑play decoding procedure that injects tool specifications into constrained decoding to improve tool selection, format correctness, and argument/value accuracy. Prior work already delivers the core of this idea. “Don’t Fine‑Tune, Decode: Syntax Error‑Free Tool Use via Constrained Decoding” and Wang et al. (2024) both propose model‑agnostic, inference‑time constrained decoding that parses tool/API documentation, builds lookup structures/FSMs or tries, and masks invalid tokens so that generated tool names, arguments, and formats are valid, showing large gains across multiple LLMs and benchmarks (including API‑Bank). Wang et al. (2023) and “Grammar‑Constrained Decoding for Structured NLP Tasks without Finetuning” further generalize the same training‑free, constraint‑driven decoding paradigm. Relative to this, the submission’s main delta is an “order consistency” heuristic that aggregates multiple sampled parameter orders via majority voting to reduce value/order errors, plus some implementation and benchmarking choices (regex extraction, specific benchmarks, model sweep). This delta is peripheral to the shared core idea of tool‑aware constrained decoding. Since the central contribution is substantially overlapped by existing constrained‑decoding methods for tool use, the overall novelty is not sufficient for a top‑tier venue.
